What it does

End-to-end enquiry-to-quote pipeline. Gmail IMAP polls the client's ops inbox → an AI scorer ranks each new message → high-scoring messages auto-create enquiries, mid-scoring go to a review queue → field extraction lifts mode, ports, weight, and incoterm → the enquiry lands on a six-column Kanban → agents are dispatched over SMTP for rates → replies are parsed (PDF / Excel / text) into structured rate rows → quotes are built with a margin calculator that hard-locks below the threshold → L1 freeze snapshots the chosen rate and advances the stage with an immutable audit row.

Architecture

A Python IMAP sidecar (gmail_proxy.py) polls Gmail every 60 seconds and POSTs to a secret-guarded ingest webhook (INGEST_SECRET) on the Express backend, decoupling inbox polling from the request path. Express runs against a single SQLite file in WAL mode (31 tables, indexed foreign keys); the React SPA is served as static assets from the same Node process behind Nginx, with TLS via Certbot and PM2 keeping the process alive under systemd. A nightly cron snapshots the database to a GCS bucket.

AI scoring (Bucket 3, integrated)

Five weighted signals score each incoming message — sender domain (30), subject keywords like quote / RFQ / freight rate (25), body terms + quantity + incoterm (20), PDF/Excel/packing-list attachment (15), first-in-thread bonus (10). Thresholds: ≥75 auto-creates an enquiry, 50–74 routes to a review queue, <50 silently skips. Tunable through a sandbox UI on the Inbox screen — Shreshta built the scorer; I wired the sandbox into the React SPA.

Margin calculator + L1 freeze (Bucket 11)

The margin tab computes Buy(INR) = Buy(USD) × exchange_rate (default 83.50, mutable in settings). A slider sets the margin 0–30%; under 12% the route hard-locks the quote with a "needs approval" badge. L1 freeze is an idempotent endpoint — it snapshots the INR conversion using the current settings.exchange_rate, advances the enquiry stage, and writes one immutable row to enquiry_timeline. Re-firing the route doesn't double-snapshot.
