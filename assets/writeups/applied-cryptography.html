CS409 · Cryptography

Applied Cryptography & Exploits

A CTF-style lab series — each challenge is a live remote service implementing a cryptographic primitive with a subtle flaw, and the assignment is to recover a flag. Theme: cryptography in textbooks is a list of primitives; cryptography in practice is a list of ways the primitives were used wrong.

IIT Bombay · Autumn 2025 Python · PyCryptodome · pwntools Labs 1–4

Lab 1 — One-time pad variants

Four challenges on weakened OTPs: two-time pad (XOR keystream reuse, recoverable via crib-dragging), modular OTP with a deterministic key expansion, a distinguishing attack on a faulty OTP with a reduced keyspace, and ciphertext recovery from a base-255 radix-encryption scheme.

Lab 2 — Block-cipher modes

Attacks across AES modes:

  • ECB — exploit the deterministic mode's pattern-leaking to extract structure from ciphertexts.
  • CBC with IV = key — payload injection that lets the attacker recover the key from a single decryption oracle.
  • CTR keystream reuse — the server reuses the same (key, nonce) pair across encryptions. Because CTR XORs plaintext with a deterministic keystream, the XOR of two ciphertexts equals the XOR of their plaintexts: P_flag = C_flag ⊕ (P_known ⊕ C_known).
  • CBC-PKCS#7 padding oracle — classical Vaudenay attack.

Lab 3 — MACs & hash collisions

HMAC timing side-channel

The target verified MAC tags with a byte-by-byte loop that short-circuited on the first mismatch — and each matching byte introduced a 1-second artificial delay, simulating timing variance. The attack measures latency with time.perf_counter(), averages over TRIALS=3 samples per candidate byte, and walks the tag forward one byte at a time. The first 10 hex characters of the tag fall to this in seconds.

Merkle–Damgård collisions (diamond structure)

Bonus challenge: a chosen-target-forced-prefix collision against an MD-style hash, built via the diamond-structure birthday attack at 2n/2 cost. Construct a converging tree of collisions, then for any forced prefix find a suffix that lands on the precomputed target — making the hash construction itself the source of the vulnerability. This is exactly why modern designs (SHA-3, sponge construction) abandon the Merkle–Damgård paradigm.

Lab 4 — Public-key & signatures

ECDSA nonce reuse → private key recovery

A textbook failure mode: signing two different messages with the same nonce k leaks the private key in a few lines of modular arithmetic. This is the exact mistake Sony made on the PS3 — the same one. Solving it implements the derivation directly.

Other challenges in this lab: RSA-OAEP decryption with a malformed oracle, X.509 certificate parsing under adversarial input, an EdDSA variant forgery, and a custom cipher broken by search-space reduction.

Tooling

Solutions are written in Python against PyCryptodome for the primitives (Crypto.Cipher.AES, Crypto.Util.strxor, Crypto.Util.Padding) and pwntools for remote-server interaction. The standard hashlib and time modules cover the MAC and side-channel work.

What stuck

These weren't toy exercises — each one was a live network service, and most labs took longer to set up the attack harness than to execute the actual exploit. That ratio is the lesson: most cryptographic break-ins are engineering work, not cryptographic genius.
